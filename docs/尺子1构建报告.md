### 2.1 已修掉的问题

| # | 问题 | 影响 | 修法 |
|---|---|---|---|
| 1 | **HumDial 重复计数**：每样本有 `X.wav` 与 `clean_X.wav` 两版，被当成两条 | 清单虚高 62%（1,441 → 889） | 只收 raw，clean 挂 `audio_clean` 字段 |
| 2 | **访客指令混进 S0**：非主用户对助手说话 51 条，属设计文档"范围外" | 污染 FRR 分母 | 单列 `S0_guest`，不计入 FRR |
| 3 | **路径混用**：相对/绝对混用 | runner 找不到文件 | 统一 `audio_root + audio`，加 `audio_ok` 标记 |
| 4 | **WearVox 下载截断**：tree API 每页 1,000 条，只请求一次 | 714/1,082 音频从未下载（清单 S1 只覆盖 162 条） | fetch.py 跟 `Link: rel="next"` 翻页（实测 7,688 文件 / 8 页），按清单补下 128 MB |
| 5 | **HumDial 文本口径**：整段转写含多说话人 | 模型看到开头提问就判响应，S1 假性 0% | 清单加 `segments`/`target_text`，runner 默认只判当前 VAD 段 |
| 6 | Chorus 7 段对话缺 timeline | 静默丢 103 轮 | 显式告警，不再黑盒 |

### 2.2 各集映射规则

| 集 | 规则 |
|---|---|
| ChorusDuplex | 主用户 = 该对话中对助手说话最多者（数据驱动）；对助手说→S0；非主用户对助手说→S0_guest；主用户对旁人→S1；旁人对主用户→S2；旁人之间→S3；`backchannel/interruption`→REG |
| WearVox | `[Active]`→S0；`[Mute]`+`unrelated_talk`→S1；`[Mute]`+`bystander_only`→S3 |
| HumDial | `talk_to_others`→S1；`others_talk_to_user_before/after`→S2；`backchannel`/`pause`→REG；只判最后一段（产品 VAD 口径） |

## 5. 复现

```bash
cd ~/repos/projects/duplex-voice/tools/ruler1
DATA=~/.hermes/workspace/ruler1/data

python3 fetch.py BiggestWave/ChorusDuplex-SideTalk $DATA/chorus  --jobs 6
python3 fetch.py zlinao/WearVox                    $DATA/wearvox --jobs 6
python3 fetch.py ASLP-lab/HumDial-FDBench          $DATA/humdial_dl --jobs 1
unzip -oq $DATA/humdial_dl/Humdial-Track2-Test.zip "test/cn_test_nondev/*" -d $DATA/humdial

python3 build_manifests.py --dataset all --data $DATA --out manifests
python3 make_mini.py --manifests manifests --out manifests/mini.jsonl      # 380 条最小集
python3 rule_baseline.py --manifest manifests/mini.jsonl --out predictions/a0__mini.jsonl
python3 score.py --manifest manifests/mini.jsonl --pred predictions/a0__mini.jsonl --sweep
```
