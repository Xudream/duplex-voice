## 2. 评测集设计

### 2.1 两把尺子的分工

| 尺子 | 数据 | 用途 | 决策权 |
|---|---|---|---|
| 尺子1（公开集） | ChorusDuplex、WearVox、HumDial-FDBench | **淘汰赛**：把 8–10 个候选筛到 2 个 | 只做淘汰，不做最终定选 |
| 尺子2（自建集） | 音箱远场 + 手机近场实测 | **定选 + 验收**：中文真实声学、S1 主场景 | 最终结论以尺子2 为准 |

理由：公开集覆盖面广但形态不对（英文/眼镜/合成），自建集贴产品但规模小、拿不到业界坐标。两者互补，不可互相替代。

### 2.2 场景定义与判定口径

| 场景 | 定义 | 正确动作 | 进哪个指标 |
|---|---|---|---|
| S0 | 主用户对助手说（真指令/答句） | respond / ack / wait | FRR 分母 |
| S0_guest | **非**主用户对助手说（访客指令） | — | 单列，**不计入 FRR**（外部设计文档 §1.3.1 划为范围外） |
| S1 | 主用户转向旁人说话 | silent | 拒识率（权重 0.40） |
| S2 | 旁人对主用户说话（非对设备） | silent | 拒识率（权重 0.15） |
| S3 | 旁人之间说话 | silent | 拒识率（权重 0.25） |
| S4 | 媒体/电子人声（电视、外放、播报） | silent | 拒识率（权重 0.20） |
| REG | 用户附和、停顿处理 | 不设门槛 | 只验不退化 |

> S0_guest 单列是本轮修订的关键：它曾混在 S0 里，直接把 FRR 分母污染成"该响应的包含访客指令"。

### 2.4 统计功效：样本量与可分辨差异

Wilson 区间公式：`半宽 = 1.96·√(p(1−p)/n)`；可分辨差异 ≈ `2 × 半宽`。

| 盘 | 应静默样本 | 假设 p | 95% CI 半宽 | 可分辨差异 |
|---|---:|---:|---:|---:|
| S1（主指标） | 986 | 0.90 | ±1.9 pt【实测】 | ~3.8 pt |
| S2 | 752 | 0.90 | ±2.1 pt【实测】 | ~4.2 pt |
| S3 | 315 | 0.90 | ±3.3 pt【实测】 | ~6.6 pt |
| S0（FRR） | 629 | 0.03 | ±1.3 pt【实测】 | 只能判"是否 ≤5%" |
| 原计划 HumDial SDO 子集 | 只有 200 | 0.90 | ±4.2 pt【估算】 | ~8 pt（**不能用来选型**） |

### 2.5 三条口径纪律

1. **dev/test 隔离**：prompt、阈值、规则只在 dev 上调；test 只报一次，触碰即该版本作废。
2. **只报分布不报单点**：所有指标给点值 + 95% CI；差异小于 CI 宽度一律写"不可区分"。
3. **一票否决不参与加权**：误执行（应静默却触发工具）恒为 0，出现即淘汰。

### 2.6 输入构造三要素

| 要素 | 规格 | 实现状态 |
|---|---|---|
| 音频 | 各集原始声道布局，只允许重采样，不做增强 | ✅ 清单带 `channels`/`layout` |
| 系统态 | `idle` / `speaking` 二值显式给定 | ✅ 清单带 `system_state` |
| 多轮历史 | 最近 5 轮转写，纯文本，**不得含 addressee 标签** | ✅ 清单带 `history`（多数集为空，缺省不编造） |

第 4 个隐含要素是 **判什么文本**（v1.1 补入）：

| 口径 | 含义 | 何时用 |
|---|---|---|
| `--text-mode full` | 整段转写一起判 | 模拟"没有 VAD 分段"的最差情况 |
| `--text-mode last`（默认） | 只判当前 VAD 段，前面的话只当背景 | **产品真实形态** |

这一条决定成绩差 19 个百分点（见 §4.3），不是细节。

### 2.7 判分规则（动作协议）

模型输出：`{"action": "...", "confidence": 0.0-1.0, "p_silent": 0-100, "reason": "≤20 字"}`

| 优先级 | 规则 |
|---|---|
| 1 | 解析失败 / 动作不在白名单 → `invalid`（>1% 该模型出局） |
| 2 | `silent` / `silent_record` → 判静默 |
| 3 | `clarify` → 判"非静默"，单列，不计入拒识率分子、不计入 FAR |
| 4 | `respond` / `ack` / `wait` → 判响应（应静默样本即误响应；S0 样本算正确） |
| 5 | 应静默样本上触发工具调用 → 记"误执行"（一票否决） |

### 2.8 指标定义

| 指标 | 公式 | 备注 |
|---|---|---|
| 分场景拒识率 | `Rej_s = 正确静默_s / 应静默_s` | 按 S1–S4 分别出 |
| 加权误响应率 | `FAR_w = Σ w_s(1−Rej_s)` / `Σw` | w：S1 0.40 / S2 0.15 / S3 0.25 / S4 0.20，缺场景自动归一 |
| 漏响应率 | `FRR = S0 被置静默数 / S0 总数` | 承诺 ≤3%，内部目标 2% |
| 误执行 | 计数 | 报 `0/N`，一票否决 |
| clarify 率 | `clarify / 总样本` | 监控 ≤2%，不计入 FAR |
| 决策延迟 | 提交 → 动作返回 | 报 P50/P90 |

### 2.9 工作点与显著性

- **工作点扫描**：有 `p_silent`（0–100）时按 `p_silent ≥ t` 判静默，t 取 50–95；否则退回"低置信度回退静默"。报三条：`FAR_w=5%` 处的 FRR、`FRR=3%` 处的 FAR_w、FAR–FRR 曲线。
- **单模型指标**：Wilson 区间（p 接近 0/1 时比正态近似稳）。
- **两模型同批样本**：McNemar 配对检验。
- **AUC 差**：Bootstrap 1,000 次报差值 CI。
- **多模型**：Holm 校正。

### 2.10 硬淘汰线与选型打分卡

硬淘汰（任一触发即出局）：误执行 > 0、invalid > 1%、S1 拒识 < 80%、决策延迟 P90 > 800 ms、必须出境且无替代方案。

通过后按加权排序（满分 100）：

| 维度 | 权重 | 计分 |
|---|---:|---|
| S1 拒识率 | 30 | 80%→0 分，95%→满分 |
| FAR_w @ FRR≤3% | 25 | 5%→满分，15%→0 分 |
| 误执行余量 | 15 | 0 次满分（出现即淘汰，本项用于排名区分） |
| 决策延迟 P90 | 10 | ≤300 ms 满分，800 ms→0 分 |
| 可部署性 | 10 | 端侧满分 / 私有化 7 / 仅 API 3 |
| 成本（每千次） | 10 | ≤¥1 满分，¥10→0 分 |

## 3. 评测集构建

### 3.1 获取：三个坑与修法

| 坑 | 现象 | 根因 | 修法 |
|---|---|---|---|
| HF 目录列表截断 | WearVox 只下到 994 个 wav，清单 1,082 条里 714 条永远拿不到 | HF tree API 每页最多 1,000 条，脚本只请求一次 | 跟 `Link: rel="next"` 翻页（实测 8 页 / 7,688 文件） |

### 4.3 发现一：最大的杠杆不是模型，是"喂哪段文本"

HumDial 的样本结构是「先两轮对助手的提问 + 末段转向旁人」。整段喂进去时，模型的原话理由是：

> **"连续两个技术问题，明显对助手提问"** → respond

所以 humdial/S1 是 **0%**。改成只判当前 VAD 段后：

| 口径 | humdial/S1 | 整体 S1 | FRR |
|---|---:|---:|---:|
| 整段（full） | 0% | 38.3% | 5.0% |
| 当前段（last） | 55% | 57.5% | 6.7% |

**这不是模型能力问题，是协议问题**：产品里 VAD 已经分段，只该判当前段。runner 默认值已改为 `last`。

### 4.4 发现二：提示词能换拒识率，但代价是 FRR

v2 加了两条规则（多说话人取最后一句；对旁人陈述/念稿不算请求）：

| 配置 | S1 | S2 | S3 | FAR_w | FRR |
|---|---:|---:|---:|---:|---:|
| 当前段 + v1 | 57.5% | 32.2% | 63.3% | 45.42% | 6.7% |
| 当前段 + v2 | 73.3% | 57.8% | 75.0% | 29.06% | 16.7% |
| 当前段 + v3 | 75.8% | 58.9% | 71.7% | 28.65% | 21.7% |

拒识率是被"更爱闭嘴"换来的，不是判得更准——FRR 从 6.7% 涨到 21.7%。

### 4.5 发现三：置信度饱和，工作点扫不动

qwen 的 `confidence` 只落在 **0.95 / 0.98** 两个值，阈值从 0.05 扫到 0.95 结果**一模一样**。
改让模型输出 `p_silent`（0–100）后：

| 指标 | 数值 |
|---|---|
| S0（应响应）p_silent 中位数 | 5 |
| S1–S3（应静默）p_silent 中位数 | 97 |
| AUC（区分应静默/应响应） | 0.780 |
| S0 中 p_silent ≥ 90（**自信地判错**） | 22%（13/60） |

那 22% 在任何阈值下都静默 → **FRR 地板就是 21.7%**，怎么调都过不了 5%。

### 4.6 A0 传统分类器对照

配置：字符 1–3 gram TF-IDF + 逻辑回归（balanced, C=1.0）+ sigmoid 校准，5 折交叉验证。

| 方法 | S1 | S2 | S3 | FAR_w | FRR | AUC |
|---|---:|---:|---:|---:|---:|---:|
| A0（阈值 0.5） | 95.6% | 100.0% | 90.6% | 5.14% | 61.7% | 0.838 |
| qwen-plus · 当前段 · v3 | 75.8% | 58.9% | 71.7% | 28.65% | 21.7% | 0.780 |

三条读法（顺序不能反）：

1. A0 拒识全面领先，但 FRR 61.7%——60 条该响应的砍掉 37 条，产品不可接受；
2. **这对比对 A0 有利**：A0 是交叉验证（训练见过同分布），LLM 是 zero-shot（一条训练样本没见过）；
3. 真正可比的是 AUC：0.838 > 0.780 → 判别力够，卡点在概率不可校准、工作点不可控。

### 4.7 分集诊断（当前段 + v3）

| 集 | S1 | S2 | S3 | 判断 |
|---|---:|---:|---:|---|
| chorus | 78% | 89% | 90% | 可用；TTS 合成、声学干净 |
| wearvox | 80% | — | 53% | S1 可用；旁人对旁人偏弱 |
| humdial | 70% | 29% | — | 真实中文，S2 几乎不可分 |

humdial/S2 只有 29%：**没有说话人标记时，"旁人问他"与"他问助手"在文本上无法区分**——这是文本通道的信息上限，只能靠空间线索（双声道/DoA）或说话人分离解决。

### 4.8 判定

| 判据 | 要求 | 实测最好 | 结论 |
|---|---|---|---|
| S1 拒识 | ≥ 80% | 75.8%（LLM）/ 95.6%（A0） | LLM ❌ 差 4.2pt；A0 达标但 FRR 崩 |
| FRR | ≤ 5% | 最好的 5.0% 出现在 S1 只有 38.3% 的配置上；S1 达标时 FRR 地板 21.7% | ❌ 同时满足者不存在 |
| 误执行 | 0 | 0 | ✅ |
| invalid | ≤ 1% | 0.53% | ✅ |
| 延迟 P50 | ≤ 800 ms（云端） | 1023–1241 ms | ⚠️ 超线 |

**通用 Qwen 直接当裁判：淘汰。** 三条替代路径：

1. **专用小模型微调**（0.6B–4B）：S1 训练数据只能来自自建集（FDBench 的 SDO 训练集是 0 条）
2. **加空间线索**：双声道/DoA 解决 humdial/S2、wearvox/S3
3. **模型级联**：0.6B 快筛 + 9B 复判（正是 L3 快慢融合的形态）

## 附录 A 指标公式

```
Rej_s       = 正确静默_s / 应静默_s
FAR_w       = Σ_s w_s (1 − Rej_s) / Σ_s w_s        # S1 .40 / S2 .15 / S3 .25 / S4 .20
FRR         = S0 被置静默数 / S0 总数
clarify 率  = clarify 数 / 总样本
CI 半宽     = z·√(p(1−p)/n),  z = 1.96
最小可分辨差 ≈ 2 × CI 半宽
```
