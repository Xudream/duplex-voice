S4（媒体/电子人声）冒烟集方案

> 背景：尺子1 的三套公开集里 S4 为 0 条（没有任何媒体/电子人声样本），而设计文档给 S4 定的目标是拒识率 ≥95%、误执行 = 0。

> 本文给一个 200 条、3 天可完成的最小采集方案，用于冒烟验证与阈值初调，不作为验收依据（验收见尺子2）。

1. 目标与判据

项内容
目的验证系统能否把"电视/外放/语音消息里的指令式台词"判为静默
规模200 条（每段 10–30 s）
通过线S4 拒识率 ≥ 95%；误执行 = 0（台词触发工具调用即失败）
统计功效n=200、p=95% → Wilson 95% CI ±3.0pt，只能判"是否明显不达标"，不能判 1–2pt 差异
不做什么不做主观体验评分、不做多房间声学覆盖（留给尺子2）

2. 素材构成（200 条）

类别条数其中"指令式台词"采集方式说明
电视直播/剧集8030音箱 2m，电视外放新闻、电视剧、综艺各占一部分
短视频外放6015手机外放（0.5 m）+ 音箱 2m 各一版抖音/快手类，语速快、背景音乐重
播客 / 有声书4010音箱 2m单人长讲，接近连续语音
语音消息 / 语音播报205手机外放 0.5 m微信语音、导航播报

"指令式台词"定义：句中包含可直接当指令的短语（"打开空调""把枪放下""放首歌""导航到…"），这是最容易触发误执行的类型，必须单独标注、单独统计。

3. 采集规范

项要求
设备摆位音箱：客厅 TV 正前方 2 m；手机：桌面 0.5 m、手持 0.2 m 各若干
设备状态电视开/关两态；手机外放开/关两态（用于区分"媒体源"与"环境噪声"）
时长每段 10–30 s，含完整一句话 + 前后各 1 s 静音
元数据每条记录：source_type（tv/drama/variety/shortvideo/podcast/audiobook/voicemsg/nav）、has_imperative_phrase（bool）、has_wakeword（bool）、distance_m、snr_db、device（speaker/phone）
命名<source>_<idx>_<device>_<dist>.wav + 同名 .json（元数据 + 用的台词片段文本）
合规只保留 10–30 s 片段用于内部评测，不整片存档；文本片段仅记录"是否含指令词"，不保存完整台词

4. 标注与验收

  • 段级 gold_action：S4 全部为 silent；另设 20 条 S0 对照（同一房间、主用户对设备下指令）用于确认"不是把所有声音都拒掉"
  • 双人标注只标三件事：来源类型、是否含指令式台词、是否可听清（可听清 = 应当能判出来）
  • 一致性：只需 κ ≥ 0.8（标签少，易达标）

5. 三天排期

天工作产出
D1素材选取与切片（公开媒体 140 段 + 自录 60 段）200 个 wav + 元数据
D2音箱/手机两种设备补录 + 标注完整采集表
D3跑批（复用尺子1 的 harness）+ 出表S4 拒识率、误执行、按来源类型分组

6. 接入方式（无需改代码）

S4 冒烟集就是一份 manifest，字段与尺子1 完全一致：


{"id":"s4-tv-0001","dataset":"s4_smoke","split":"dev","audio_root":".../s4","audio":"tv_0001_speaker_2m.wav",
 "channels":1,"layout":"mono","system_state":"idle","history":[],
 "gold_action":"silent","gold_scene":"S4","gold_lang":"zh","transcript":"",
 "meta":{"source_type":"tv","has_imperative_phrase":true,"snr_db":12.0},"audio_ok":true}

跑法与尺子1 相同：


python3 llm_judge.py --manifest manifests/s4_smoke.jsonl --backend openai_compat \
  --base-url https://dashscope.aliyuncs.com/compatible-mode/v1 --model qwen-plus \
  --out predictions/qwen-plus__s4.jsonl
python3 score.py --manifest manifests/s4_smoke.jsonl --pred predictions/qwen-plus__s4.jsonl --only-predicted

> 注：S4 的输入是音频，文本裁判只能评"ASR 转写后的判定"，会漏掉"音乐/环境声但无转写"的情况。因此 S4 建议同时跑跑道 B（端到端模型），否则会高估拒识率。
