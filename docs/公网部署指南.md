# duplex-voice 公网部署指南（App 客户端 + 服务端模式）

> 分支：feat/hermes-app-server
> 适用：Linux 服务器公网/局域网部署，App（Android/iOS）或浏览器远程连接
> 部署形态：Caddy（自动 HTTPS）+ Docker（server）+ 设备 token 鉴权

## 1. 部署形态

```
App / 浏览器（公网）
   │ HTTPS/WSS (443)
   ▼
Caddy 反代（自动证书：Let's Encrypt 公网 / mkcert 局域网）
   │ HTTP 内部转发 (127.0.0.1:8787)
   ▼
duplex-voice server（Docker：ASR/TTS/LLM 全在这，key 只存在服务器）
```

要点：
- **API key 永不出服务器**（App 端零密钥，泄露面只剩服务端 config.yaml）
- Caddy 选型原因：自动 HTTPS 证书管理（iOS WKWebView 麦克风要求安全上下文，
  公网域名直接 Let's Encrypt，无域名局域网用 mkcert 自签+App 端装根证书）

## 2. 服务器要求

- Linux x86_64/arm64，2C4G 起步（server 本身轻，重活在云端 DashScope）
- 开放 443；8787 仅监听 127.0.0.1（不直接暴露）
- Python 3.11+（或直接 Docker）

## 3. 部署步骤（Docker + Caddy）

```bash
# 3.1 代码
git clone https://github.com/Xudream/duplex-voice.git   # 或私有仓
cd duplex-voice && git checkout feat/hermes-app-server

# 3.2 API key（config.yaml 不入 git——手工放真实 key）
cp config.yaml config.yaml.local   # 参考
vim config.yaml                     # model.dashscope_api_key 填真实 key

# 3.3 启动 server（只绑 127.0.0.1）
docker compose up -d
curl http://127.0.0.1:8787/api/health   # {"ok":true,"key":true,...}

# 3.4 Caddy（公网域名版 /etc/caddy/Caddyfile）
voice.example.com {
    reverse_proxy 127.0.0.1:8787
}
#   无域名局域网版（自签）：
#   tls internal   # Caddy 内置 CA，App 端信任其根证书即可

systemctl reload caddy
```

Docker compose 关键改动（公网部署用）：`ports: ["127.0.0.1:8787:8787"]`。

## 4. 开启设备鉴权（公网必做）

```bash
# config.json → server.auth.required = true（或面板 ⚙️ 里改，热生效）
curl -X POST http://127.0.0.1:8787/api/config -H 'Content-Type: application/json' \
  -d "$(curl -s http://127.0.0.1:8787/api/config | jq '.config | .server.auth.required=true' -c | jq -c '{config: .}' ...)"
# 简化：直接改 web/config.json 后 POST 全量配置热生效

# 设备注册（首次配对，最好在服务器本地/局域网做）
curl -X POST http://127.0.0.1:8787/api/device/register \
  -H 'Content-Type: application/json' -d '{"name":"my-phone"}'
# → {"token":"dvt_...","device_id":"dev_..."}   # token 只显示这一次，App 端存好

# App WS 连接时首条 hello 带 token；错 token → auth_error 断开
```

注意：注册端点本身无鉴权（先有鸡问题），公网建议注册完在防火墙封
`/api/device/register`，或后续加一次性配对码。

## 5. 验收清单

- [ ] `curl https://<域名>/api/health` → ok:true
- [ ] 浏览器打开 `https://<域名>` → 页面加载，麦克风可授权（HTTPS 生效标志）
- [ ] WS：`wss://<域名>/api/stream` hello + 文本轮收到 fast/slow/audio_chunk
- [ ] auth.required=true 时：错 token 收 auth_error
- [ ] 服务器 `ss -tlnp | grep 8787` → 仅 127.0.0.1 监听

## 6. 安全清单

| 项 | 局域网 | 公网 |
|----|--------|------|
| auth.required | false | **true** |
| 8787 监听 | 0.0.0.0 可 | **仅 127.0.0.1**（Caddy 转发） |
| API key | 服务器 config.yaml | 同左（600 权限，不入 git） |
| HTTPS | 可选（mkcert） | 必须（Let's Encrypt） |
| 设备注册端点 | 开放 | 注册后封闭 |
| 日志（/api/logs） | 开放 | 注意含对话内容，建议加鉴权（P2） |
