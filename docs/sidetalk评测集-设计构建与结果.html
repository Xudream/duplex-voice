1.2 一句话结论

尺子1 已建成 3,309 条、音频 100% 就位的公开集评测盘；用 380 条最小集跑了 3 个 Qwen 判官 + 1 个传统分类器基线，没有任何方案同时满足「S1 拒识 ≥80%」和「FRR ≤5%」——通用大模型 zero-shot 当判官这条路，已经被数据否掉，下一步必须走专用小模型微调。

2. 评测集设计

2.1 两把尺子的分工

尺子数据用途决策权
尺子1（公开集）ChorusDuplex、WearVox、HumDial-FDBench淘汰赛：把 8–10 个候选筛到 2 个只做淘汰，不做最终定选
尺子2（自建集）音箱远场 + 手机近场实测定选 + 验收：中文真实声学、S1 主场景最终结论以尺子2 为准

理由：公开集覆盖面广但形态不对（英文/眼镜/合成），自建集贴产品但规模小、拿不到业界坐标。两者互补，不可互相替代。

2.5 三条口径纪律

  1. dev/test 隔离：prompt、阈值、规则只在 dev 上调；test 只报一次，触碰即该版本作废。
  2. 只报分布不报单点：所有指标给点值 + 95% CI；差异小于 CI 宽度一律写"不可区分"。
  3. 一票否决不参与加权：误执行（应静默却触发工具）恒为 0，出现即淘汰。

2.7 判分规则（动作协议）

模型输出：{"action": "...", "confidence": 0.0-1.0, "p_silent": 0-100, "reason": "≤20 字"}

优先级规则
1解析失败 / 动作不在白名单 → invalid（>1% 该模型出局）
2silent / silent_record → 判静默
3clarify → 判"非静默"，单列，不计入拒识率分子、不计入 FAR
4respond / ack / wait → 判响应（应静默样本即误响应；S0 样本算正确）
5应静默样本上触发工具调用 → 记"误执行"（一票否决）

2.8 指标定义

指标公式备注
分场景拒识率Rej_s = 正确静默_s / 应静默_s按 S1–S4 分别出
加权误响应率FAR_w = Σ w_s(1−Rej_s) / Σww：S1 0.40 / S2 0.15 / S3 0.25 / S4 0.20，缺场景自动归一
漏响应率FRR = S0 被置静默数 / S0 总数承诺 ≤3%，内部目标 2%
误执行计数报 0/N，一票否决
clarify 率clarify / 总样本监控 ≤2%，不计入 FAR
决策延迟提交 → 动作返回报 P50/P90

2.9 工作点与显著性

  • 工作点扫描：有 p_silent（0–100）时按 p_silent ≥ t 判静默，t 取 50–95；否则退回"低置信度回退静默"。报三条：FAR_w=5% 处的 FRR、FRR=3% 处的 FAR_w、FAR–FRR 曲线。
  • 单模型指标：Wilson 区间（p 接近 0/1 时比正态近似稳）。
  • 两模型同批样本：McNemar 配对检验。
  • AUC 差：Bootstrap 1,000 次报差值 CI。
  • 多模型：Holm 校正。

2.10 硬淘汰线与选型打分卡

硬淘汰（任一触发即出局）：误执行 > 0、invalid > 1%、S1 拒识 < 80%、决策延迟 P90 > 800 ms、必须出境且无替代方案。

通过后按加权排序（满分 100）：

维度权重计分
S1 拒识率3080%→0 分，95%→满分
FAR_w @ FRR≤3%255%→满分，15%→0 分
误执行余量150 次满分（出现即淘汰，本项用于排名区分）
决策延迟 P9010≤300 ms 满分，800 ms→0 分
可部署性10端侧满分 / 私有化 7 / 仅 API 3
成本（每千次）10≤¥1 满分，¥10→0 分

4.3 发现一：最大的杠杆不是模型，是"喂哪段文本"

HumDial 的样本结构是「先两轮对助手的提问 + 末段转向旁人」。整段喂进去时，模型的原话理由是：

> "连续两个技术问题，明显对助手提问" → respond

所以 humdial/S1 是 0%。改成只判当前 VAD 段后：

口径humdial/S1整体 S1FRR
整段（full）0%38.3%5.0%
当前段（last）55%57.5%6.7%

这不是模型能力问题，是协议问题：产品里 VAD 已经分段，只该判当前段。runner 默认值已改为 last。

4.4 发现二：提示词能换拒识率，但代价是 FRR

v2 加了两条规则（多说话人取最后一句；对旁人陈述/念稿不算请求）：

配置S1S2S3FAR_wFRR
当前段 + v157.5%32.2%63.3%45.42%6.7%
当前段 + v273.3%57.8%75.0%29.06%16.7%
当前段 + v375.8%58.9%71.7%28.65%21.7%

拒识率是被"更爱闭嘴"换来的，不是判得更准——FRR 从 6.7% 涨到 21.7%。

4.5 发现三：置信度饱和，工作点扫不动

qwen 的 confidence 只落在 0.95 / 0.98 两个值，阈值从 0.05 扫到 0.95 结果一模一样。

改让模型输出 p_silent（0–100）后：

指标数值
S0（应响应）p_silent 中位数5
S1–S3（应静默）p_silent 中位数97
AUC（区分应静默/应响应）0.780
S0 中 p_silent ≥ 90（自信地判错）22%（13/60）

那 22% 在任何阈值下都静默 → FRR 地板就是 21.7%，怎么调都过不了 5%。

4.6 A0 传统分类器对照

配置：字符 1–3 gram TF-IDF + 逻辑回归（balanced, C=1.0）+ sigmoid 校准，5 折交叉验证。

方法S1S2S3FAR_wFRRAUC
A0（阈值 0.5）95.6%100.0%90.6%5.14%61.7%0.838
qwen-plus · 当前段 · v375.8%58.9%71.7%28.65%21.7%0.780

三条读法（顺序不能反）：

  1. A0 拒识全面领先，但 FRR 61.7%——60 条该响应的砍掉 37 条，产品不可接受；
  2. 这对比对 A0 有利：A0 是交叉验证（训练见过同分布），LLM 是 zero-shot（一条训练样本没见过）；
  3. 真正可比的是 AUC：0.838 > 0.780 → 判别力够，卡点在概率不可校准、工作点不可控。
